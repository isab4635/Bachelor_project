# Bachelor_project

This repository is for the bachelor project "Treating rheumatoid arthritis — trajectories, correlations and predictions based on a large nationwide dataset" running during spring 2026 at the Healthtech department at the Technical University of Denmark.

The code found here are copies of the scripts on the remote server, which is not synced to GitHub. 

There are two folders: Misc_scripts and Scripts. The scripts folder containing all scripts used in the main pipeline and for generating all main figures and models in the project. The scripts folder also have a folder for each of the two subquestions in the project containing the similar files just tweaked for each subquestion.
